# 선택형 기록 파일럿 사전 계획

후보 조회 전 규칙 커밋은 `6c394d0`이다. Vendure v3.5.0의 첫 부모 이력과 UTC 커미터 일시, 제목을 [선정 규칙](selection.md)대로 필터링했다. 적격 여부를 확인한 순서는 다음과 같다.

[실제 발화와 부모 리비전](protocol.json)을 고정한다. 첫 과업은 A→B, 둘째는 B→A. 성적을 보고 순서를 바꾸지 않는다. 기존 ChatGPT 로그인 Codex CLI 0.171.0-alpha.13.2, 요청 모델 gpt-6.2-sol / medium. 매 작업자는 별도 부모 아카이브에서 읽기 전용 CLI로 시작한다. 외부 검색·앱·플러그인·메모리·하위 agent 사용을 끈다. 최초 조사 응답 후 같은 대화 ID로 재개한다. B만 두 번째 턴에 한 번 선택권을 본다. 요청 없이는 작성자 호출이 없다. 요청 시 새 작성자 사본에는 원래 과업·질문과 독립된 CLI 도구만 둔다. 첫 기록의 text를 편집 없이 같은 B 대화에 전한다. 일반 소스 검토와 공개 CLI 사용은 작성자의 선택이다.

준비 시 기존 계정에서 제공된 7일 사용 창은 15% 사용이었다. 별도 결제 없이 작업자 4세션, 작성자 최대 2세션이다. 역할별 CLI 활성 경과 최대 360초, 응답 완료 시 누적 입력 650,000·출력 15,000 토큰 운영 한도, 도달하면 같은 역할의 다음 턴을 시작하지 않는다. 단일 턴 안에서의 초과는 전액 기록한다. 작업자당 기본 2턴(B가 요청하면 전달 후 최대 3턴), 작성자 1턴. 최대 12개 참가자 CLI 턴, 활성 시간 합 최대 36분이다. 재시도나 대체 세션은 없다. 진행자가 순서를 바꾸지 않고 연속 집행한다. 토큰·모델·시간·실패는 가용 계측만 표시하고 사용량 결측 등 집행 장애 시 남은 집행을 보류한다. 작업자의 활성 시간에서 작성 대기를 제외한다. 최초 요청부터 계획까지의 연속 경과에 작성 대기는 한 번 포함된다. 로컬 요청/응답 이벤트와 CLI 턴 수는 구분하며 관측되지 않은 전송·실패 횟수를 추정하지 않는다.

## 가림 판정

첫 계획의 text만 임의 순서의 식별자로 제시한다. 품질 문서를 먼저 봉인하고 그 뒤에 역할·질문·사용량과 appendix를 연다. 각 행마다 충족·누락·오류·판정 불가와 근거를 남긴다. 같은 동작을 보존하는 다른 설계를 인정한다. 첫 계획에 구체적인 검증 제안이 있어야 회귀 항목을 충족한다. 패치 실행·통과는 평가하지 않는다.

| ID | 채점할 조건 |
| --- | --- |
| M1 | 상점의 두 active 목록과 PublicPaymentMethod / PublicShippingMethod 결과 타입의 customFields 노출을 연결한다. |
| M2 | 스키마의 실제 설정 기반 필드 타입과 공개 필터(internal 및 public=false 제외)를 보존한다. |
| M3 | 결제·배송 양쪽 서비스에서 값(관계형 필드 포함)을 실제 반환할 경로를 설명한다. |
| M4 | 기존 목록의 채널 범위, 결제 enabled, 배송 soft-delete 및 번역을 보존한다. |
| M5 | 두 목록의 공개 필드를 질의해 값까지 확인하는 회귀와 숨긴 필드 또는 잘못된 목록 항목에 대한 음성 검사를 제안한다. |
| S1 | slug로 여러 후보 중 상품 ID를 고르는 시점에 현재 채널에 배정된 상품만 남긴다. |
| S2 | 삭제 제외와 기존 언어 우선순위(요청 언어, 채널 기본 언어, 기타)를 보존한다. |
| S3 | 찾은 ID를 기존 조회 경로에 넘기는 동작(요청 relations 포함)과 미발견 동작을 보존한다. |
| S4 | 서로 다른 채널에 같은 slug를 가진 별도 상품을 두고 각 채널에서 자기 상품을 반환하는 대조를 명시한다. |
| S5 | 기존 언어 처리 또는 삭제·미발견 동작을 검증하는 구체적인 추가 회귀 사례를 제안한다. |

채점 뒤 요청 시점·이유, 작성자가 처음 발견한 수단, 첫 조사와 최종 판단 사이의 새 사실·재확인·오류를 소스와 대조한다. 양 조건이 같은 결과면 실제 비용을 그대로 비교한다. 사람 수요, 단독 CLI/FCA 효과, 일반적인 품질이나 비용 우위는 미측정이다.
