1. `vendure/packages/core/src/service/services/product.service.ts`의 `ProductService.findOneBySlug`에서 `product.channels`를 내부 조인하고, `ctx.channelId`를 바인딩해 `getRawOne()`이 ID를 고르기 전에 후보를 현재 채널로 제한합니다. 지금은 전체 채널에서 ID 하나를 고른 뒤 `findOne`이 채널 소속을 검사하므로, 다른 채널의 후보가 먼저 선택되면 현재 채널에 일치 상품이 있어도 빈 결과가 나옵니다. 채널 소속 조건의 근거는 `vendure/packages/core/src/entity/product/product.entity.ts`의 `Product.channels`와 `vendure/packages/core/src/connection/transactional-connection.ts`의 `TransactionalConnection.findOneInChannel`입니다.

2. 번역 언어와 관계없이 입력 slug를 찾는 조건, 삭제 상품 제외, 요청 언어 → 채널 기본 언어 → 기타 언어 순의 후보 정렬을 보존합니다. 선택된 ID와 `relations`는 기존 `ProductService.findOne`에 전달해 관계 로딩과 응답 번역을 유지합니다. Shop·Admin의 ID 조회와 인자 규칙, Shop의 비활성 상품 제외와 비공개 패싯 필터링도 그대로 적용합니다. 근거는 `vendure/packages/core/src/service/helpers/translator/translator.service.ts`의 `TranslatorService.translate`, `vendure/packages/core/src/api/resolvers/shop/shop-products.resolver.ts`의 `ShopProductsResolver.product`, `vendure/packages/core/src/api/resolvers/admin/product.resolver.ts`의 `ProductResolver.product`입니다.

3. `vendure/packages/core/e2e/product-channel.e2e-spec.ts`에서 두 하위 채널에 같은 영어 slug를 가진 상품을 각각 생성하고 한쪽에만 독일어 번역을 추가합니다. 두 채널에서 같은 slug를 독일어로 요청해 각각 자기 상품 ID를 반환하는지 확인합니다. 영어만 있는 채널은 영어 응답을, 독일어 번역이 있는 채널은 독일어 응답을 기대합니다. 이 구성에서는 기존 쿼리가 영어만 있는 채널에서도 독일어 후보를 먼저 고르므로 회귀를 재현할 수 있습니다. 현재 채널에 일치 상품이 없고 다른 채널에만 있는 경우는 `null`을 확인합니다. `vendure/packages/core/e2e/product.e2e-spec.ts`의 기존 ID 조회, 없는 slug, 기본 언어 폴백, 교차 언어 slug, 에셋·변형 로딩 사례도 검증합니다.
