# 주문 작업 후 화면 동기화

실험용 주문 상세 화면에서 취소·환불 대화상자를 닫으면 요청, 알림, 이력 갱신 및 주문 재조회 없이 끝낸다. 제출해 하나 이상의 변경 요청을 보냈다면, 그 요청들의 업무 결과가 결정된 뒤 화면의 이력 갱신과 해당 주문 재조회를 각각 한 번 수행한다. 부분 취소와 여러 결제 환불이 연이어 실행되는 경우도 하나의 작업이다. 서버가 업무 오류를 반환해 일부만 성공하거나 전부 거절해도 화면을 한 번 동기화한다.

취소와 환불의 대상·내용·순서, 선행 취소 실패 시 환불 중단과 기존 환불 결과별 안내를 보존한다. 직접 취소에서 서버가 주문 대신 업무 오류를 반환하면 그 메시지로 실패를 알리고 성공 안내는 하지 않는다. 성공한 직접 취소에서는 기존 성공 안내를 유지한다. 통신 자체의 예외와 서버 정책은 범위 밖이다.
