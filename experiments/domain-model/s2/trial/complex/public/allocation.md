# 여러 결제에 환불액 배분

실험용 Vendure 관리 화면의 로컬 정책이다. 환불 합계를 자동 배분할 때 선택한 결제 중 남은 환불 가능액이 작은 결제부터 소진하고, 가능액이 같으면 화면에 처음 표시된 순서를 따른다. 어떤 결제도 남은 가능액을 초과하지 않는다. 이 우선순위가 화면의 결제 순서나 제출할 환불 요청의 순서를 바꾸면 안 된다.

기존 품목·배송 합계, 수동으로 지정한 합계, 결제별 이전 환불과 실패한 환불의 처리, 선택하지 않은 결제와 부분 취소의 동작을 보존한다. 범위는 합계를 다시 배분하는 경우다. 새 서버 정책이나 개별 결제의 금액 편집 방식 변경은 요구하지 않는다.
