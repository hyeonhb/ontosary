## 어떤 차이가 재현됐는가

배정·입력·채점 대조를 고정한 커밋은 `face060`으로, 첫 참가 호출의 시작 기록과 일치했다. C의 기록은 동결 blob 그대로이고 B와 C의 근거 링크 열 개가 동일한 순서로 일치했다. 참가자에게는 자료 경로를 안내했고 B·C 네 세션 모두 첫째 또는 둘째 응답에서 기록을 읽었다. 저장된 111개 요청의 패킷 해시, 배정과 제출 순서, 패치 해시를 확인했다. [사전 배정](../../experiments/first-use/excalidraw-arrow-comparison/allocation.json) · [자료 대응표](../../experiments/first-use/excalidraw-arrow-comparison/materials.md)

고정 upstream 트리에서 설치 사본을 새로 만들고, 참가 모델 호출 없이 원본·기준 수정본·봉인 패치 네 건을 채점했다. 원본은 목표 화살표가 남았고 기준 수정본과 네 패치는 경로 안 일반 화살표만 지웠다. 두 장면에서 원래 ID의 삭제 플래그와 비삭제 장면 포함 여부, 기존 올가미 6건이 보관 결과와 일치했다. 각 제출의 회귀 테스트만 원본에 적용하면 실패했고 해당 제출의 구현과 함께 적용하면 통과했다. 네 구현은 공통으로 기존 한 점 거리 판정을 살리고 두 표본 사이의 교차를 검사했다. [검토한 첫 패치와 실행 기록](../../experiments/first-use/excalidraw-arrow-comparison/observations)

## 성공률과 비용 해석

차이를 만든 것은 패치의 제출 시점이다. A2와 B1도 참가자의 자체 테스트가 통과했지만, 마지막 셸 작업 뒤 입력 한도에 도달해 별도의 제출 호출을 할 수 없었다. 두 작업 사본은 공식 패치로 봉인되지 않았으므로 숨은 장면에서의 정답 여부는 미측정이다. A1과 B2 역시 한도를 넘었지만 마지막 응답이 제출이어서 채점됐다. 모두 사전 규칙과 일치한다.

C는 A보다 입력이 133,433개(15.7%) 적고 시간은 11.8초 더 걸렸다. 둘 다 성공한 첫 묶음에서는 C가 입력 71,244개와 15.7초를 줄였다. 둘째 묶음은 같은 품질에 도달한 A가 없어 이 차이의 반복 여부를 판정할 수 없다. 매 요청에 누적 행동·도구 출력이 다시 들어가므로 입력 차이에는 조사 내용, 명령 출력 길이와 제출까지의 호출 수가 함께 반영된다. 기존 기록의 작성·독립 검토 비용에는 결측이 있어 순비용 절감도 미확인이다.

응답별 사용량을 다시 합산한 결과 입력 2,408,962개와 출력 20,818개였다. 마지막 응답 직전까지는 전체 입력 2,373,826개였다. 그 응답에서 생긴 초과 8,962개를 포함했고 이후 호출은 없었다. 모든 호출 직전의 세션·전체 토큰 합계가 해당 운영 한도 안에 있었음을 확인했다.

이 사례에서 확인한 신호는 동결 원문을 받은 두 세션이 더 적은 합산 입력으로 모두 제출까지 마쳤다는 점이다. A도 같은 수정·회귀 판단에 도달했고 잠금 보존은 공통 요청에 명시돼 있었다. 포맷의 일반적 우위, FCA의 기록 구축 기여, 사람의 도입 의향은 별도 질문이다. 같은 과업의 반복은 여기서 마감한다. 합의한 다음 논의는 실제 업무 범위에서 FCA가 검토할 만한 관계를 제시할 수 있는지다.
