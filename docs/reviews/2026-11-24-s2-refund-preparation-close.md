# S2 독립 리뷰 · 환불 잔액 과업의 준비 마감

2026-11-24. PR #96의 최종 커밋 `248b5a6`을 검토해 R23을 닫았다. 이전 리뷰에서 닫은 R24·R25의 결과도 유지됐다. 환불 잔액 과업의 탐색·최종 수정 측정 준비는 합의한 범위에서 완료됐다. [이전 리뷰의 종료 조건](2026-11-24-s2-refund-grading-fix-independent-review.md) · [수정한 바인딩 판정](../../experiments/domain-model/s2/trial/discovery/template.ts)

| 대조 | 독립 관측 |
| --- | --- |
| 바깥 버튼의 `; then null` | 같은 제출 지문에서 수정 전 11/11이던 결과가 `ngIfThen` 미지원으로 바뀌었다. Angular 구문 오류는 0개이며 사례 실행과 점수 부여 전에 멈춘다. |
| 원본·문구만 수정·두 정상 구현 | 원본과 문구만 수정한 제출은 각각 9/11, 공유 판별 함수를 수정한 대조와 새 잔액 함수를 사용한 A/B/C 제출은 각각 11/11이다. 안쪽 `else cancelOnly`의 두 문구와 실제 클릭 경로를 유지했다. |
| 추가 바인딩 판정 | 고정 Angular 19.2.15로 원래 템플릿과 바깥 조건의 `; else null`, `as visible` 변형을 파싱해 같은 바인딩 판정 함수에 전달했다. 원래 두 번역 키는 그대로 읽혔고, 두 변형은 각각 추가 입력과 지역 변수를 명시하며 미지원으로 멈췄다. |

PR head에서 의존성을 고정 lockfile대로 확인하고 4,735개 Vendure 소스 파일에서 시작한 작업 사본 13개를 새 출력 위치에 재생했다. 새 반례를 제외한 12개 결과는 종전 기록과 일치했다. 세 조건의 봉인된 탐색 기록과 루프백 요청 9개의 기록은 각각 기존 파일과 바이트 단위로 일치했다. `pnpm check`의 타입 검사·테스트 304개·예제 빌드와 `pnpm experiment`의 기존 비교 4개가 통과했다. 실제 참가 호출은 0회다. 이번 종료 판단은 지원하는 메뉴 구조의 점수와 미지원 범위를 구별할 수 있는지에 관한 것이다. Ontosary가 실제 에이전트의 탐색 비용을 얼마나 줄이는지는 후속 실험에서 측정할 항목이다. 다음 우선순위는 Vendure의 실제 이슈나 변경 PR에서 국소 수정만으로는 보존 요구를 충족할 수 없는 과업 하나를 선정하는 일이다. 그 과업과 독립 판정 근거가 정해진 뒤 실행 횟수와 비용을 결정한다.
