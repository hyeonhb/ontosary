# S2 개발 지시 · 같은 Vendure 수정 과업에서 Sol의 성공과 비용 비교

Astra는 소스와 업무 요구만 받은 A에서 6건 모두 성공했다. 같은 두 과업을 `gpt-6.2-sol`, 추론 강도 `medium`으로 실행해 두 질문에 답해 주세요. **Sol이 소스만으로 놓치는 변경·보존 요구를 도메인 자료가 보완하는가? Sol에 자료를 제공하면 Astra+A에서 관측한 첫 패치 품질에 어느 비용으로 도달하는가?** 이번 결과의 단위는 고정 입력을 받은 독립 세션의 첫 제출입니다. [Astra 독립 리뷰](2026-11-20-s2-complex-comparison-independent-review.md)

## 실행 범위

- Vendure 잔여 수량과 화면 동기화 두 과업을 사용합니다. 각 과업에서 A는 공통 소스·업무 요구, B는 A에 구조화 뷰를 추가한 입력, C는 A에 서술 문서·근거 부록을 추가한 입력입니다. 과업·조건당 3회, 총 **최대 18회**입니다. Astra 때의 과업·조건·반복 순서, 패킷 원문, 패치 적용 규칙, v3 평가기와 기준 소스를 유지해 주세요. [동결 계약](../../experiments/domain-model/s2/results/2026-11-19-complex-grading-v3/contract.json)
- 첫 호출 전에 Sol 전용 실행 계약과 결과 위치를 정하고, 새로 구성한 여섯 패킷의 바이트가 Astra 입력과 같은지 확인해 주세요. 기존 로그인 CLI에서 Sol·medium, 참가자 도구 비활성, 가장 긴 패킷과 응답 예산을 수용하는 문맥을 확인합니다. 실행 기록에서 요청 모델과 실제 사용 모델을 대조할 근거도 확보해 주세요. 실행기에서 필요한 국소 수정과 검증 방법은 개발 세션이 정합니다. [기존 실행기](../../experiments/domain-model/s2/trial/complex/holdout.py)
- 매회 새 세션에서 첫 응답 한 개를 수집합니다. 참가자에게 다른 응답이나 채점 결과가 전달되지 않게 하고, 시도별 원응답·사용량·상태를 Sol 배치에 봉인해 주세요. 중단 후에는 기존 시도 기록을 확인해 중복 호출을 막습니다. 별도 교정 호출, 실패 재시도, Astra 재실행은 예산에 포함되지 않습니다.
- 기존 예산을 적용합니다. 회당 제한 시간은 1,800초이며 입력 82,000·출력 8,000토큰 및 첫 응답 49,152바이트는 기존 계약대로 사후 판정합니다. 총 입력 984,000~1,092,000·출력 3,600~72,000토큰은 계획 추정치입니다. Sol 사용 경로나 입력 보존을 확인할 수 없거나 추가 결제·다른 인증이 필요해지면, 남은 호출 전에 근거와 선택지를 알려 주세요.

## 결과 판정과 인계

1. **Sol 내부의 자료 효과.** 과업별로 A/B/C 각각의 완전 성공을 3건 중 몇 건인지, 합계를 조건별 예정 6건 중 몇 건인지 적어 주세요. 패치 적용 거부, 타입·업무 동작 실패, 인프라 중단을 구분하고, 업무 차이가 나온 경우 해당 변경 또는 보존 사례와 패치를 연결합니다. 실패를 포함한 조건별 총 입력·출력·경과 시간과 B−A, C−A 차이를 제시합니다. 추가 성공당 비용은 비교 가능한 조건에서 성공 차이가 양수일 때만 계산합니다. 미관측 비용은 결측으로 두고, 인프라 문제로 비교가 불완전하면 효과 판정을 보류합니다.
2. **기존 Astra+A와의 비교.** 기준은 완전 성공 6/6, 입력 226,482·출력 3,827토큰입니다. Sol+A, Sol+B, Sol+C를 각각 대조해 어느 과업에서 같은 성공 건수에 도달했는지와 비용 차이를 보여 주세요. Sol+A도 이미 성공한 경우를 드러내야 자료의 기여를 판단할 수 있습니다. 모델별 비용 환산에는 같은 기준일·서비스 경로에 적용되는 공개 단위와 캐시 처리를 명시합니다. 근거가 없으면 토큰·시간만 보고하고 금액·크레딧 절감 여부는 미확정으로 둡니다. 같은 주간 사용량 창에서 관측 가능한 플랜 변화폭은 사용자에게만 별도로 전달합니다. [기존 채점·비용 원자료](../../experiments/domain-model/s2/results/2026-11-20-complex-comparison/score/summary.json)
3. **완료 기준.** 새 호출 없이 Sol의 봉인 자료에서 등급과 비용표를 다시 만들 수 있고, 기존 Astra 결과도 그대로 재현되어야 합니다. 저장소 검사와 재현 명령, 기준 리비전, 중단·누락이 있으면 해당 시도와 해석에 미치는 영향을 결과 PR에 담아 독립 리뷰로 인계해 주세요. 결론은 두 과업에서 관측한 범위로 한정합니다. 도구를 사용하는 저장소 탐색, FCA의 모델 구축 기여, 모델 작성·유지 비용 및 B/C의 최종적인 업무 의미 동등성은 별도 검증 항목입니다.
