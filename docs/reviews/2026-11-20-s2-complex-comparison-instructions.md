# S2 개발 세션 지시 · Vendure 고정 입력 A/B/C 비교 실행

두 실험용 업무 정책과 v3 계약의 실행 예산을 승인했다. 같은 모델이 변경 전 도메인 지식을 받았을 때 올바른 첫 패치를 몇 건 더 만들고, 그 추가 성공에 사용량이 얼마나 드는지 관측해 주세요. [준비 결과 독립 리뷰](2026-11-19-s2-complex-grading-v3-independent-review.md) · [실행 순서와 예산](../../experiments/domain-model/s2/results/2026-11-19-complex-grading-v3/contract.json)

- **업무 정책.** 잔여 수량은 주문 당시 수량에서 모든 결제의 해당 항목에 대한 비실패 환불 수량을 뺀다. 제출로 변경 요청을 보냈으면 모두 거절된 경우까지 포함해 업무 결과가 결정된 뒤 이력과 주문을 각각 한 번 갱신한다. 대화상자를 닫기만 하면 조용히 끝낸다. 참가자는 이미 동결된 공개 요구와 조건별 패킷을 받는다.
- **실행.** 준비된 고정 입력 환경에서 수량·화면 동기화 두 과업에 A(공통 소스와 요구), B(구조화 뷰 추가), C(대응하는 서술 문서·근거 부록 추가)를 각각 3회 배정한다. 총 18개 독립 세션에서 기존 ChatGPT 로그인 CLI로 `gpt-6.2-astra`, 추론 강도 `medium`, 도구 없는 첫 응답 한 개를 수집한다. 새 수집을 시작하기 전에 동일 배치가 이미 시작됐는지 확인하고, 중단 시 기존 실행 기록을 사용한다. 승인 범위는 기존 접속 경로와 동결된 18회다. 추가 크레딧 구매나 유료 경로 전환이 필요하면 그 시점에 사용자와 논의한다.
- **예산과 사용률.** 계획 범위는 총 입력 984,000~1,092,000토큰, 출력 3,600~72,000토큰이다. 회당 1,800초, 입력 82,000·출력 8,000토큰과 응답 49,152바이트의 집행·사후 판정은 기존 계약을 따른다. 사용자가 구독 한도 소모 비율도 궁금해하므로 가능한 경우 수집 직전·직후 같은 주간 사용량 창을 읽어 변화폭을 **퍼센트포인트**로 사용자에게 알려 주세요. 동시 사용이나 한도 갱신이 있으면 그 영향을 설명한다. 이 값은 개인 계정 관측이므로 공개 저장소에는 싣지 않는다.
- **결과 인계.** 기존 실행기의 `stage`·`collect`·`score` 경로를 사용한다. 18개 기회의 원응답 또는 중단 상태를 기록한 뒤 채점하고 모델 재호출과 사람 보정은 하지 않는다. 과업·반복별 첫 패치 결과, 조건별 예정 6건의 완전 성공 수, 실패를 포함한 입력·출력·경과 시간과 누락값을 보고한다. B−A와 C−A는 비교가 가능하고 추가 성공이 양수일 때만 추가 성공당 비용을 산출한다. 업무 동작이 실제로 갈린 사례를 소스와 연결하고, B/C 표현 효과를 설명할 때는 업무 의미 동등성에 대한 사람의 검토 상태를 명시한다. 재현 가능한 결과 PR을 독립 리뷰에 인계하면 완료다.
