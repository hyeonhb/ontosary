# Vendure 변경 계획 두 건에서 선택형 도메인 기록을 요청했는가

**두 과업 모두 B는 첫 조사 뒤 기록을 요청하지 않고 변경 계획을 제출했다.** A와 B의 첫 계획 네 건은 각각 사전 업무·회귀 기준 5개를 모두 충족했다. 작성 세션, 전달된 기록, 작성 대기는 모두 0건이다. 따라서 이번 관측으로는 기록을 받았을 때 달라지는 판단이나 작성 비용 대비 효용을 추정할 수 없다. ## 과업별 선택과 결과

비용은 **최초 계획까지 경과 초 / 계측된 모델 응답 수 / 입력·출력 토큰** 순이다. A는 일반 검색, B는 같은 도구로 먼저 조사한 뒤 한 번만 기록을 요청할 수 있었다.

| 과업 | 첫 계획 A · B | 선택 시점의 의문 → B가 직접 확인한 근거 | A 총비용 | B 총비용 |
| --- | --- | --- | --- | --- |
| 상점의 결제·배송 수단에 공개 사용자 정의 필드 노출 | 5/5 · 5/5 | 요청 0. 두 활성 목록을 찾은 상태에서 공개 필드가 없을 때의 값 노출과 관계 조회가 의문이었다. 공통 스키마와 resolver 등록을 읽고 공개 필드가 있을 때 기존 타입을 연결하는 계획을 냈다. | 87.375초 / 11회 / 247,478·3,199 | 72.758초 / 9회 / 178,210·2,657 |
| 서로 다른 판매 채널에서 같은 상품 주소 사용 | 5/5 · 5/5 | 요청 0. ID 선택 전 채널 필터가 필요함을 이미 찾았고, 중복 주소를 재현할 픽스처가 남았다. 두 하위 채널의 토큰 전환과 채널·언어별 중복 검사를 읽고 양방향 회귀 사례를 제안했다. | 51.697초 / 8회 / 124,391·1,744 | 55.400초 / 7회 / 111,173·1,995 |

**결제·배송 수단.** A는 주문이 있어야 쓰는 적격 수단 견적부터 조사했고 두 번째 턴에서 주문 없이 조회하는 활성 목록을 찾았다. B는 첫 조사에서 두 조회를 이미 구별했다. 같은 5/5에 B의 입력은 69,268토큰, 경과는 14.617초 적었다. 두 경로의 차이는 선택 안내 전에 이미 있었다. 두 계획은 공개 필드가 하나도 없을 때 필드를 생략할지 null을 반환할지에 차이가 있었다. 이 세부 계약은 사전 채점 항목 밖이다. [A의 조사 기록](../../experiments/first-use/optional-note/2026-11-27/sessions/methods-A.json) · [B의 조사와 선택](../../experiments/first-use/optional-note/2026-11-27/sessions/methods-B.json) · [상류 수정](https://github.com/vendurehq/vendure/commit/bb4723d7ac6172124b0603f8dc12744da3ed9fed)

**상품 주소.** 두 작업자 모두 첫 조사에서 후보 ID를 고른 뒤에 채널을 검사하는 순서가 문제임을 찾았다. 두 계획 모두 각 채널에서 자기 상품 ID가 나오는지 확인한다. B는 한 상품에만 요청 언어의 번역을 두어 잘못된 후보가 먼저 선택되게 하는 사례까지 구체화했다. B의 입력은 13,218토큰 적었고 출력은 251토큰 많았으며 경과는 3.703초 길었다. 두 B 모두 미요청 사유를 별도로 진술하지 않았다. 위 표는 실제 남긴 의문과 그 뒤의 조사 경위를 연결한 것이다. ## 실행과 비용 근거

Vendure v3.5.0 이력에서 선정 규칙을 통과한 첫 두 건을 사용했다. 사전 계획 커밋은 `3827577e5a648c573f4b4a913c4567c147819c1a`다. 각 작업 디렉터리에는 해결 전 리비전의 소스·당시 일반 문서가 들어 있는 vendure 디렉터리만 두었다. 실행 뒤 파일 경로와 Git blob을 부모 트리에 대조해 결제·배송 사본 두 개에서 각각 4,169개, 상품 주소 사본 두 개에서 각각 4,173개가 일치했다. 작업자는 각자 새 대화에서 시작해 자기 대화에서 재개했다. CLI 여덟 턴의 로컬 설정은 모두 gpt-6.2-sol / medium이었다. 실제 서버 모델명은 독립 확인하지 못했다. 작업자의 CLI 시작부터 마지막 종료까지를 경과로 잡았다. 두 턴 사이에는 진행 스크립트가 첫 출력을 검사하고 다음 안내를 넘겼으며 수동 개입은 없었다. 사본 준비는 표에 별도로 표시했다. 진행자의 과업 선정·채점 시간은 미계측이다. 작성자 활동과 대기, 기록을 읽는 후속 턴은 모두 0이다.
