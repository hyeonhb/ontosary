# 업무 개념·관련 코드 탐색 실험 — 절차 초안

작성: 2026-11-08. **미실행 / 대상·참가자 미확정.** 사용자 선택(ADR-014)에 따른 후속 준비이며 R4/R5 수정의 유용성 검증 결과가 아니다. 현재 utility corpus의 24개 라벨 승인과 실제 사용자 과업을 분리한다. 이번에는 제품 기능이나 실험 UI를 구현하지 않았다.

## 대상과 질문을 실행 전에 고정

다음 별도 세션에서 공개/허가된 실제 업무 애플리케이션 하나를 선정하고 repo/revision/license/tsconfig/분석 범위·설정 비용을 기록한다. 사적 코드는 허가 범위를 확인한다. 참가자의 기존 코드 친숙도도 기록한다. 새 LLM·SMT·프레임워크 플러그인 없이 현 facts가 어떤 근거를 제공하는지부터 본다.

과업 초안은 “이 애플리케이션에서 **주문 취소**를 이해하려면 어떤 타입·상태·조건·처리 코드와 표시 코드를 확인해야 하는가? 근거 위치와 연결 이유를 제시하고, 확정할 수 없는 연결은 따로 표시하라”다. 실제 선택한 앱에 이 개념이 존재하고 과업이 의미 있는지 원문·제품 문서로 먼저 확인한다. 이는 후보 질문이며 아직 target나 정답을 고정한 것은 아니다. 대상에 맞춰 질문을 바꾸거나 사용자 방향을 바꿔야 하면 변경 이유와 선택지를 제시한다.

실행 전에 채울 고정 입력:

| 항목 | 현재 상태 |
| --- | --- |
| 앱/revision/라이선스/범위 | 미선정 |
| 업무 개념과 정확한 질문/시작 지점 | 위 초안, 대상 확인 후 확정 |
| 필수·허용·비관련 코드 위치와 조건 근거 | 미작성; 소스와 기존 제품 문서에서 독립 작성 |
| 정답 작성자·사람 검토자/이견 | 미확정; 코드 사실과 업무 해석을 분리 |
| 참가자·TS 경험·원본 친숙도 | 미모집; agent를 사람으로 세지 않음 |
| 제공 도구·표시 형식·버전·실행 순서 | 아래 설계 초안, 실행 전 동결 |

## 비교 조건과 학습 효과

A는 소스 검색/LSP 탐색, B는 A + 동일 facts의 단순 type/property 공유 그룹, C는 A + 동일 facts의 FCA 후보/intent/관계다. B/C는 같은 분석 범위·근거 링크·표시 형식·시간 한도를 사용한다. 그룹 수의 증가를 가치로 세지 않는다. 코어 한도 초과·미지원은 그대로 보여주며 범위를 줄이면 세 조건 모두 동일하게 줄인다. 자동 업무 의미 승인이나 생성된 의미 이름으로 조건을 유리하게 만들지 않는다.

첫 노출을 비교하려면 참가자마다 한 조건만 배정한다. 참가자 경험/친숙도를 기록하고 조건별 균형 배정을 실행 전에 정한다. 목표는 소규모 탐색 pilot(예: 조건별 2명)이며 모집 가능성을 아직 확인하지 않았다. 한 사람에게 같은 과업을 A→B→C로 반복시키면 답을 외우는 효과가 있으므로 그 시간을 독립적인 효용 비교로 쓰지 않는다. 한 명만 가능하면 한 조건의 정성 관찰로 한정하거나 후속 동등 과업 설계를 먼저 검토한다. 적은 표본으로 일반화/유의성 주장을 하지 않는다.

## 정답·시간·비용 기록

도구 결과를 보기 전에 소스/문서에서 정답 근거 목록을 작성하고 별도 사람이 검토한다. 의미가 모호한 항목은 논쟁 항목으로 남기고 확정 정답에서 분리한다. 평가자는 가능하면 조건을 모르는 상태로 제출물을 검토하며, 자동 링크 대조와 업무 해석 판정을 별도로 기록한다.

환경 준비·분석 시간과 사람이 과업을 푸는 시간을 분리한다. 과업 시간은 동일 질문/자료를 공개한 시점부터 제출 또는 사전 고정 시간 한도(초안 15분)까지다. 도움 요청·도구 오류·중단과 이유를 기록한다. 성공한 응답만 남기지 않는다. 원시 시간과 완수 여부를 함께 보며 미완수를 빠른 성공으로 계산하지 않는다.

제출물은 관련 코드/조건 위치, 각 연결의 근거, 불확실한 연결, 최종 설명이다. 평가 항목은 근거 목록 도달/누락/잘못된 연결, 근거를 확인한 수, 불필요한 후보 검토량, 근거 없는 업무 의미 단정, 실제 시간, 설정/유지 비용이다. 동일 extent에 FCA의 intent/관계 설명만 더해지는 경우에도 도움이 됐는지 별도로 묻는다.

## 결과 해석과 중단 기준

사람의 검토 기록이 없으면 자동 지표만 보고하고 탐색 시간이 줄었다고 쓰지 않는다. FCA가 단순 그룹보다 정확한 근거 도달을 돕지 않거나 검토 부담·오해를 늘리면 축소 여부를 검토한다. 입력/검증 가정이 맞는 경우에만 기존 논리 비교를 보조 근거로 사용하며 이번 실험의 전제조건으로 삼지 않는다.

모든 결과를 날짜별로 보존하고 개선 후보 하나를 관찰 근거로 제안한다. 실제 지원 결함/false proof가 나오면 최소 재현을 별도 보존해 정확성을 먼저 다룬다. 대상·정답·참가자·절차가 확정되기 전에는 실험 준비 완료나 Gate 2~4 통과로 표시하지 않는다.
